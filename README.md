# Практична робота №7-8 (JavaScript)

## Опис
До існуючого HTML/CSS сайту додано інтерактивність за допомогою JavaScript.

## Реалізовано:
- Підключено зовнішній файл main.js
- Підсвічування активної сторінки
- Мобільне меню (бургер)
- Перемикач теми (збереження в localStorage)
- Кнопка "Вгору" + плавний скрол
- Акордеон (FAQ)
- Модальне вікно
- Валідація форми
- Лічильник символів
- Збереження чернетки форми (localStorage)
- Обробка submit через FormData

## Структура проєкту
lab01-html/
├─ index.html
├─ pages/
│ ├─ about.html
│ └─ contact.html
├─ assets/
├─ styles/
│ ├─ style.css
│ └─ responsive.css
├─ js/
│ └─ main.js

## Як запустити
Відкрити файл **index.html** у браузері або через Live Server.
