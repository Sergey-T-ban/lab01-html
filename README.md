# Практична робота №5-6 (CSS)

## Опис роботи
У цій роботі було оформлено багатосторінковий HTML-сайт за допомогою CSS.

## Що реалізовано:
- Підключено зовнішні файли стилів (style.css, responsive.css)
- Створено єдиний дизайн для всіх сторінок
- Використано кольорову палітру через CSS-змінні
- Оформлено:
  - навігацію (Flexbox)
  - текст (заголовки, абзаци)
  - списки
  - зображення
  - таблицю
  - форму (input, textarea, button)
  - відео та аудіо
- Використано Flexbox (меню + сторінка "Про мене")
- Додано hover та focus ефекти
- Реалізовано адаптивність через media queries

## Структура проєкту
lab01-html/

│ ├─ about.html
│ └─ contact.html

## Як запустити
Відкрити файл **index.html** у браузері або через Live Server.
